### 5.1 问题

C031 将 FlashAttention kernel 列为保留差距。C032 在当前架构（HF attention + 物理缓存后处理）内保证物理 KV cache 操作的清晰性和可复用性。

当前 `GPUModelRunner._prefill_batch()` 和 `_decode_batch()` 中，物理缓存写入代码重复且耦合到具体执行路径。

### 5.2 变更

**提取可复用函数**到 `v1/worker/gpu_model_runner.py`：
```python
def _write_kv_to_physical_cache(self, past_key_values, slot_mapping, valid_mask):
    """将 HF past_key_values 扁平化后写入 GPU 物理张量。
    
    Args:
        past_key_values: HF 模型返回的 per-layer (K, V) tuple
        slot_mapping: [num_tokens] int64 — 每个 token 的物理 slot ID
        valid_mask: [num_tokens] bool — 哪些 token 需要写入
    """
    for layer_idx, (layer_k, layer_v) in enumerate(past_key_values):
        bsz, nheads, seq, hdim = layer_k.shape
        k_flat = layer_k.permute(0, 2, 1, 3).reshape(bsz * seq, nheads, hdim)
        v_flat = layer_v.permute(0, 2, 1, 3).reshape(bsz * seq, nheads, hdim)
        reshape_and_cache_pytorch(
            k_flat[valid_mask], v_flat[valid_mask],
            self.kv_cache_k[layer_idx], self.kv_cache_v[layer_idx],
            slot_mapping[valid_mask],
        )
```

_prefill_batch 和 _decode_batch 均调用此方法，消除重复。

## 六、步骤 5 — 对齐 Scheduler.update_from_output 流程

### 6.1 问题

C031 标准控制流：
```

  1. scheduler_output = scheduler.schedule()
  2. model_output = executor.execute_model(scheduler_output)
  3. engine_core_outputs = scheduler.update_from_output(scheduler_output, model_output)
  4. return output_processor.process_outputs(engine_core_outputs)
```

### 6.2 新增 `v1/outputs.py` 中的 `EngineCoreOutputs`

```python
@dataclass
class EngineCoreOutputs:
    """Output from Scheduler.update_from_output()."""
    finished_requests: list = field(default_factory=list)
    sampled_token_ids: dict[str, list[int]] = field(default_factory=dict)
```

### 6.3 变更：`v1/core/sched/scheduler.py`

添加 `update_from_output()` 方法：
```python
def update_from_output(
    self,
    scheduler_output: SchedulerOutput,
    model_output: ModelRunnerOutput,
    eos_token_id: int,
    max_tokens: int,
) -> EngineCoreOutputs:
    """根据执行结果更新所有 request 状态。
    
    1. 将采样 token 写入各 request
    2. 检查 stop 条件（EOS / max_tokens）
    3. 标记 finished request
    4. 返回结构化 EngineCoreOutputs
    """
    finished: list[Request] = []
    for rid, token_ids in model_output.sampled_token_ids.items():
        req = self._find_request(rid)
        if req is None:
            continue
        for tok in token_ids:
            if tok == eos_token_id:
                req.status = RequestStatus.FINISHED_STOPPED
                break
            req.append_output_token_ids(tok)
        if req.num_output_tokens >= (req.max_tokens or max_tokens):
            req.status = RequestStatus.FINISHED_LENGTH_CAPPED
        if req.is_finished():
            finished.append(req)
    return EngineCoreOutputs(
        finished_requests=finished,
        sampled_token_ids=model_output.sampled_token_ids,
    )

def _find_request(self, request_id: str) -> Request | None:
    for req in self.running:
        if req.request_id == request_id:
            return req
    return None
```

### 6.4 变更：`v1/engine/core.py`

简化 `step()`：
```python
def step(self) -> list[RequestOutput]:
    scheduler_output = self.scheduler.schedule()
    if scheduler_output.total_num_scheduled_tokens == 0:
        return []

    model_output = self.executor.execute_model(scheduler_output)
    if model_output is None:
        return []

    engine_outputs = self.scheduler.update_from_output(
        scheduler_output, model_output,
        eos_token_id=self.eos_token_id,
        max_tokens=self.max_new_tokens,
    )

    for req in engine_outputs.finished_requests:
        self._finish_request(req)

    req_map = {r.request_id: r for r in self.scheduler.running}
    return self.output_processor.process_outputs(
        model_output, req_map,
        eos_token_id=self.eos_token_id,
        max_tokens=self.max_new_tokens,
    )
```
