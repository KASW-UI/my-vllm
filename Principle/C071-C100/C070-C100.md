# 总结：C032-C100 完整依赖链

```
C032 单 GPU Runtime 基础
  │
  ├─ C033-C050  Phase 1: 单 GPU 工业化
  │   (KV Spec → Coordinator → CoW → SchedulerInterface → Triton → CUDA Graph → TP2)
  │
  ├─ C051-C070  Phase 2: 单 GPU 高级能力
  │   (Priority → Preemption → Async → KV Metrics/Offload → Sampler → SpecDecode → Grammar → Pooling)
  │
  ├─ C068        Bridge: SingleTypeKVCacheManager 补齐 (Cross/Mamba/ChunkedLocal)
  │
  ├─ C071-C095  Phase 3: 分布式 + 生态
  │   ├─ C071-C077  分布式 (Multiproc → IPC → ZMQ → PP → DP → Collective → Integration)
  │   ├─ C078-C080  Config 完善 (10 类 → VllmConfig → Observability)
  │   ├─ C081-C084  LoRA (Config → Linear → Scheduler → Runner)
  │   ├─ C085-C087  量化 dispatch (Config → ModelLoader → Linear/Attention)
  │   ├─ C088-C091  多模态 (Registry → EncoderCache → Scheduler → Runner)
  │   ├─ C092-C093  分布式收尾 (KV Connector + AsyncMPClient)
  │   └─ C094-C095  公共能力 (6 utils + EngineArgs/Protocol)
  │
  └─ C096-C100  Phase 4: SDK + 收敛
      ├─ C096-C098  SDK (LLM API → OpenAI → CLI)
      └─ C099-C100  收敛 (Benchmark + 全链路集成)
```

Config 提前到 C078-C080，让 C081 之后的 LoRA (`enable_lora=True`)、C085 之后的量化 (`quantization=awq`)、C088 之后的多模态 (`mm_config`) 都通过 `VllmConfig` 表达参数。每个 Commit 都是：**"当前系统遇到瓶颈 → 工业需求出现 → 架构演化"**。
