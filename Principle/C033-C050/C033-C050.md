# C038 — Scheduler Resource Model

这是之前遗漏的重要 commit。

真实 vLLM scheduler 不只是：

```
request queue
```

而是：

```
request

+

GPU budget

+

KV budget

+

token budget
```

修改：

```
v1/core/sched/scheduler.py
v1/core/sched/output.py
```

C032 已有：

```
SchedulerOutput:
  scheduled_new_reqs     (含 block_ids, num_computed_tokens)
  scheduled_cached_reqs
  num_scheduled_tokens
  total_num_scheduled_tokens
```

扩展：`scheduled_new_reqs` 增加 `num_new_tokens` 字段（区别于 `num_computed_tokens`，表示本次 step 实际处理的 token 数）；补齐 `preempted_req_ids` 的调度逻辑（C032 只定义了字段，未使用）。
