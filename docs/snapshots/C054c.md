# C054c: KVCacheBlock ref_cnt 级联释放 + KVCacheBlockCopy

## Goal

完善 block 池的引用计数体系。prefix cache CoW 逻辑通过 KVCacheManager 的 `_apply_cow()` 和 `take_kv_cache_block_copies()` 实现，KVCacheBlockCopy 经 SchedulerOutput 传递供 Worker 执行 GPU 端拷贝。

## New Features

- `KVCacheBlockCopy(src_block_id, dst_block_id)` — CoW 拷贝记录
- `SchedulerOutput.kv_cache_block_copies` — 传递拷贝到 Worker
- `KVCacheManager._apply_cow()` — ref_cnt > 1 时克隆共享 block
- `KVCacheManager.take_kv_cache_block_copies()` — 排空待执行拷贝
