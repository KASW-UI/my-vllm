# C001: Minimal Runtime

## Goal
运行 HuggingFace LLM 完成最小推理闭环——加载模型权重，执行一次 forward，输出 logits。

## New Features
- Tokenizer 加载（HuggingFace AutoTokenizer）
- Checkpoint 加载（HuggingFace AutoModelForCausalLM）
- 单次模型 forward pass
- Logits 输出（top-5 预测展示）

## Runtime Flow
```
prompt
  ↓
tokenizer.encode()
  ↓
input_ids
  ↓
LLM.forward()
  ↓
model(input_ids)
  ↓
logits
```

## Current Capability
- ✅ 单 prompt 推理
- ✅ 单次 forward pass
- ✅ Logits 输出

## Current Limitation
- ❌ 无文本生成（没有 decode loop）
- ❌ 无 KV Cache（每步重新计算全部历史）
- ❌ 无 Request 概念（只能处理一个隐含 prompt）
- ❌ 无 Batch 支持
- ❌ 无显存管理
- ❌ 无调度器
- ❌ 硬编码本地模型路径

## Next Stage
当前只能 forward 得到一次 logits，无法完成 token-by-token 文本生成。Commit 002 引入 autoregressive generation loop。
