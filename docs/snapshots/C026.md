# C026: Input Processing Pipeline

## Goal

Extract prompt tokenization and Request creation from
LLMEngine.add_request() into a dedicated InputProcessor,
following vLLM V1's `v1/engine/input_processor.py`.

## New Features

- `v1/engine/input_processor.py` — `InputProcessor`:
  - `process(prompt, max_new_tokens, request_id) → Request`
  - Accepts raw text strings (auto-tokenize) or pre-tokenized
    token ID lists (pass through)
  - Generates auto-increment request IDs (`req-0`, `req-1`, ...)
  - Configurable `default_max_tokens` per processor instance
- LLMEngine:
  - `self._input_processor = InputProcessor(tokenizer, ...)`
  - `add_request()` now delegates to `input_processor.process()`
  - Removed inline tokenize + Request construction

## Current Limitation

- Single prompt type only (text string or token ID list)
- No multimodal/chart input support (not needed for now)
- No prompt template / chat template rendering
