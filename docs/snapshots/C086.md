# C086: Multi-GPU Integration

## Goal

TP × PP × EP × CP 组合验证 — 拓扑布局 + 通信成本模型 + 兼容矩阵。

## New Features

- `ParallelConfig`: tp_size / pp_size / ep_size / cp_size → world_size
- `communication_cost()`: 4 种并行的 byte 级别通信开销估算
- `COMPAT_MATRIX`: TP×PP ✅, TP×EP ✅, TP×CP ✅, PP×CP ⚠️, EP×CP ⚠️
- `TOPOLOGY_8GPU_TP2_PP2_EP2`: 8 GPU 拓扑布局示例
