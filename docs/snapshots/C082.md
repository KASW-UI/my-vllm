# C082: EP (Expert Parallel) All-to-All

## Goal

将 C081 的 MoE 扩展到多 GPU — 通过 All-to-All dispatch/combine 将 token 路由到持有对应 expert 的 GPU。

## New Features

- `expert_parallel_dispatch()`: 按 expert_id // num_local_experts 计算目标 GPU，All-to-All 分发
- `expert_parallel_combine()`: 将 expert 输出送回原始 token 所在 GPU
- `v1/distributed/elastic_ep/dispatch.py` — EP dispatch 基础设施
