# C093: Autoscaling

## Goal

queue_depth 驱动的自动扩缩容 — scale_up/scale_down 决策逻辑 + 冷启动容错。

## New Features

- `AutoscalingController`: min/max replicas, queue_depth threshold, stabilization windows
- `ScalingDecision`: action + target_replicas + reason
- `cold_start_time_estimate()`: 按模型参数量估算加载时间
- `deploy/autoscaling.py` — 独立控制器模块
