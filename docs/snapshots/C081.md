# C081: MoE (Mixture of Experts)

## Goal

从零实现 MoE layer — gating + expert dispatch + fused kernel。稀疏激活降低每 token FLOPs。

## New Features

- `FusedMoERouter`: TopK gating, softmax weights, expert_indices
- `FusedMoE`: 工厂 → 创建 router + experts 列表
- `ExpertMLP`: hidden_dim → intermediate_dim → hidden_dim
- `fused_moe()`: 按 expert_indices 路由 token 到对应 expert，加权求和
