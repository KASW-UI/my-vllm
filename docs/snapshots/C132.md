## What each sub-item did

### #5 — `v1/sample/logits_processor` package

Split the 87-line single file into 4 modules matching
`vllm/v1/sample/logits_processor/{interface.py,builtin.py,state.py}`:

- **`__init__.py`** — re-exports the 3 penalty functions + the
  `LogitsProcessor` ABC for downstream users.
- **`interface.py`** — `LogitsProcessor` ABC stub (single
  `is_argmax_invariant` method). The full vLLM ABC also has
  `__call__` and `update_state`; not implemented because
  my-vLLM's penalties are stateless free functions today. The class
  exists only for the 1:1 file-tree alignment — adding a guided
  processor later requires only subclassing, not refactoring.
- **`builtin.py`** — moves the 3 penalty functions (`apply_*_penalty`)
  verbatim. Same signatures, same logic; only the module name and
  C-tag in the docstring change.
- **`state.py`** — docstring-only stub. vLLM's `BatchUpdateBuilder`
  and `LogitsProcessors` runner track per-step batch-membership
  changes so processors can update per-request state. my-vLLM's
  penalties are stateless, so the state machinery is not needed
  today; this file exists for 1:1 alignment.

Two callers unchanged (`v1/sample/sampler.py` and
`tests/test_C024_sampler.py` both already imported from
`my_vllm.v1.sample.logits_processor`, which now resolves to the
package's `__init__.py` re-export).

### #6 — `model_executor/model_loader` package

Split the 50-line single file into 5 modules matching
`vllm/model_executor/model_loader/{__init__.py,base_loader.py,
default_loader.py,utils.py,weight_utils.py}`:

- **`__init__.py`** — preserves the legacy `load_model(model_name, dtype)`
  function as a thin wrapper around `DefaultModelLoader().load_model(...)`,
  re-exports `BaseModelLoader`, `DefaultModelLoader`, `get_model_cls`,
  `get_model_architecture`, `hf_state_dict_to_model_state`.
- **`base_loader.py`** — `BaseModelLoader(ABC)` with one
  `load_model` abstract method. vLLM's ABC also has `download_model`
  and TP-aware sharding hooks; omitted as out of scope for
  my-vLLM's single-process, single-GPU path.
- **`default_loader.py`** — `DefaultModelLoader(BaseModelLoader)`.
  Moves the existing load_model body verbatim, with the
  HF state_dict streaming extracted to a `hf_state_dict_to_model_state`
  helper call.
- **`utils.py`** — `get_model_cls(model_type)` returns the registered
  model class (currently only `OPTForCausalLM`); `get_model_architecture`
  is a thin HF-type→registry-key mapper. vLLM's `utils.py` also has
  `get_architecture_class_name` and a broader registry — omitted.
- **`weight_utils.py`** — `hf_state_dict_to_model_state(hf_model, model)`
  is the extracted weight streaming logic; vLLM's `weight_utils.py`
  also handles format dispatch (safetensors / pytorch / sharded)
  and HF downloads — omitted.

Two callers (`v1/worker/gpu_model_runner.py` and
`v1/worker/gpu/model_states/default.py`) continue to import
`from my_vllm.model_executor.model_loader import load_model` — the
package re-export preserves the public API.
