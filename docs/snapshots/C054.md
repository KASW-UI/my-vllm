# C054: KV Cache Metrics

## Goal

block 生命周期可观测。在 BlockPool 的 allocate/access/free 事件上挂载 metrics 统计：跟踪每个 block 的 residency、reuse interval、eviction count。

C054 引入 vLLM 对齐的 `KVCacheMetricsCollector` + `BlockMetricsState`，通过采样降低开销，在 EngineCore 中 drain eviction events 并汇入 `SchedulerStats`。

## New Features

- `BlockMetricsState` — per-block lifecycle：birth_time, access_history, lifetime, idle_time, reuse_gaps
- `KVCacheMetricsCollector` — 采样跟踪，on_block_allocated / accessed / evicted
- `KVCacheEvictionEvent` — 驱逐事件数据：lifetime_seconds, idle_seconds, reuse_gaps_seconds
- `BlockPool` 注入 `metrics_collector`，在 get_new_blocks / touch / free_blocks 调用回调
- `SchedulerStats.kv_cache_eviction_events` 汇入驱逐事件
