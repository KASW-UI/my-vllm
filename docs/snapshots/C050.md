# C050: TP=2 Weight Sharding (Minimal)

## Goal

C032 的 TP 是 stub（world_size=1 时 identity）。C050 实现 ColumnParallelLinear 和 RowParallelLinear 的最低可行多 GPU 版本：内联 `torch.distributed.all_reduce/all_gather`。

## New Features

- `parallel_state.all_gather()` / `all_reduce()` 调用真实 `torch.distributed` 操作
- `ColumnParallelLinear.forward()`: all_gather 拼接各 GPU 输出
- `RowParallelLinear.forward()`: all_reduce 聚合 partial sum
- 下沉 `init_distributed()` 自动从 `RANK`/`WORLD_SIZE` env vars 检测
