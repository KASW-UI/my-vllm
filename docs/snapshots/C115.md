# C115: models/opt.py — field-for-field alignment with vllm OPTForCausalLM

## Goal

Bring `my_vllm/model_executor/models/opt.py` to field-for-field parity with `vllm/vllm/model_executor/models/opt.py` while preserving the manual QKV fusion (principled scope reduction: AutoWeightsLoader is out of scope for a single-model reproduction).

## New Features

### `OPTForCausalLM` class-level metadata (mirrors vllm)

```python
hf_to_vllm_mapper = WeightsMapper(
    orig_to_new_stacked={
        ".q_proj": (".qkv_proj", "q"),
        ".k_proj": (".qkv_proj", "k"),
        ".v_proj": (".qkv_proj", "v"),
    },
    orig_to_new_prefix={"decoder.": "model.decoder."},
)
packed_modules_mapping = {"qkv_proj": ["q_proj", "k_proj", "v_proj"]}
```

The `WeightsMapper` is a minimal in-file class (real vLLM's is in `model_executor/models/utils.py` and uses `@dataclass`). It declares what AutoWeightsLoader would do; my-vllm applies the same mapping inline via `_fuse_qkv_params`.

### Constructor signatures match vllm

| Class | Signature (my-vllm) | Matches vllm |
|---|---|---|
| `OPTAttention` | `(embed_dim, num_heads, bias=True, cache_config=None, quant_config=None, prefix="")` | ✓ |
| `OPTDecoderLayer` | `(config, cache_config=None, quant_config=None, prefix="")` | ✓ |
| `OPTDecoder` | `(config, cache_config=None, quant_config=None, prefix="")` | ✓ |
| `OPTModel` | `(config, prefix="")` | ✓ (vllm takes `vllm_config`, my-vllm takes config directly) |
| `OPTForCausalLM` | `(config, prefix="")` | ✓ (vllm takes `vllm_config`) |

`OPTForCausalLM(nn.Module, SupportsPP, SupportsLoRA)` → my-vllm is just `(nn.Module)` (PP=1 by config; LoRA lives in `my_vllm/lora/` package and is wired into the scheduler, not the model definition).

### `embed_input_ids` propagation

`OPTForCausalLM`, `OPTModel`, `OPTDecoder` all expose `embed_input_ids(input_ids)`, mirroring the chain in real vLLM. Used by future input_embedding pipelines (prompt-embedding prefix caching).

### `load_weights` semantics

Real vLLM: `loader = AutoWeightsLoader(self, skip_prefixes=[...]); loader.load_weights(weights, mapper=self.hf_to_vllm_mapper)`.

my-vllm: inlines the manual loop + the QKV stacking from `mapper.orig_to_new_stacked`. The shape-slicing fallback for `param.shape != wt.shape` (handles tied-embedding weight name collisions) is preserved.

## Runtime Flow

```
Tokenizer → InputProcessor → Request(prompt_token_ids, sampling_params)
   → EngineCore.add_request → Scheduler.add_request
   → Scheduler.schedule → Executor.execute_model → GPUModelRunner
        → model.forward(input_ids, positions)  # OPTForCausalLM.forward
            → OPTModel.forward
                → OPTDecoder.forward
                    → for layer in layers:
                          layer(hidden_states)
                          ├─ self_attn_layer_norm(hidden_states)
                          ├─ self_attn(hidden_states)  # OPTAttention
                          │    ├─ qkv_proj(hidden_states)  # QKVParallelLinear
                          │    ├─ chunk → q, k, v
                          │    ├─ attn(q, k, v)            # Attention.forward
                          │    │   └─ get_forward_context().attn_metadata[layer_name]
                          │    │       → impl.forward (FlashAttn | TritonAttn)
                          │    └─ out_proj(attn_output)
                          ├─ + residual
                          ├─ final_layer_norm(hidden_states)
                          ├─ fc1 → activation_fn → fc2
                          └─ + residual
                → final_layer_norm (if any) → project_out (if any)
        → OPTForCausalLM.compute_logits(hidden_states)
            → LogitsProcessor(lm_head, hidden_states)
```

## Current Limitation

- `SupportsPP` and `SupportsLoRA` are not mixin'd into `OPTForCausalLM`. PP infrastructure (`IntermediateTensors`, `make_layers`, `get_pp_group()`) is intentionally absent (PP=1 by config).
- `OPTForCausalLM.__init__` takes `config: OPTConfig` directly; real vLLM takes `vllm_config: VllmConfig` and extracts `hf_config`/`quant_config`/`cache_config` from it. The runner passes HF config directly today; VllmConfig threading is C121 territory.
- The `make_empty_intermediate_tensors` factory is not bound (vLLM OPTModel binds it for PP forward-compat). My-vllm omits it since PP=1.
