## Current Limitation

* **Pre-cleanup test failures** — 72 historical test failures
  (test_C001-C031 + test_C126-C128 + test_hot_path) are
  expected per `AGENTS.md` ("Newer commits may intentionally
  break older test expectations as the architecture evolves").
  Not regressions.
* **C212 test pollution** — `test_prompt_kv_roundtrip_attention_matches[dtype{0,1}]`
  fails when run after other tests in the same pytest session,
  passes 5/5 when isolated.  PyTorch CUDA state not reset
  between test sessions.  Pre-existing infrastructure issue.
* **No CPU offload during sleep** (C231 limitation) — tensor
  contents don't survive `sleep` / `wake_up`.  Requires
  `CudaRTLibrary` wrapper that vLLM vendors but my-vllm
  doesn't.
* **Engine-side elastic EP wiring is stubbed** (C230 limitation)
  — state machine advances enums; production TCP-store barriers
  + NCCL weight transfers deferred.
* **Engine-side attention backend coverage limited to Triton**
  (C211 limitation) — FlashAttention / FlashInfer / xFormers
  backends are ABC stubs.  TritonAttentionBackend is the
  production path.
