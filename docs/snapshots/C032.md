# C032: Cleanup — complete C031 unfinished items

## Goal

完成 C031 未完成的 4 个差距：清理 V1 层的遗留绑定、删除 C014 遗留文件、修复 model_executor 桥接层、补齐 scheduler.update_from_output 引擎闭环。

## New Features

- `Scheduler.update_from_output()` — 引擎核心流程的 finish 检测委托给调度器

- `model_executor/model_loader.py` — 内联实现，不再依赖 runtime 桥接
- 解码路径统一使用 `reshape_and_cache_pytorch` 写入物理缓存

## Runtime Flow

```
EngineCore.step()
  │
  ├─▶ Scheduler.schedule() → SchedulerOutput
  │     ├─ RequestQueue (FCFS)
  │     ├─ KVCacheManager (allocate_slots, prefix cache)
  │     └─ chunked prefill (C030)
  │
  ├─▶ Executor.execute_model(SchedulerOutput) → ModelRunnerOutput
  │     └─▶ GPUModelRunner.execute_model()
  │           ├─ request_state.add_request() / block_tables.append_block_ids()
  │           ├─ _prefill_batch() → model(**input) → _write_kv_to_physical_cache → Sampler
  │           └─ _decode_batch() → gather_cached_kv → model(**input) → reshape_and_cache → Sampler
  │
  ├─▶ Scheduler.update_from_output(SchedulerOutput, ModelRunnerOutput, eos, max_tokens)
  │     └─▶ EngineCoreOutputs { finished_requests, sampled_token_ids }
  │
  ├─▶ EngineCore._finish_request() → KVCacheManager.free() + Worker.cleanup() + Scheduler.finish()
  │
  └─▶ OutputProcessor.process_outputs() → list[RequestOutput]
        └─▶ IncrementalDetokenizer.update() → text
```

## Current Capability

- 完整 V1 目录结构和组件边界对齐
- EngineCore.step() 通过 scheduler.update_from_output() 闭环
- 物理 KV cache 预分配（GPU tensor）+ reshape_and_cache / gather_cached_kv 操作
- FCFS 调度 + chunked prefill + prefix cache
- 批处理 prefill 和解码
- AsyncLLM（asyncio.Queue，非轮询）
- InputProcessor / OutputProcessor（detokenizer）
- 11 种 RequestStatus 状态
- 结构化 SchedulerOutput / ModelRunnerOutput / EngineCoreOutputs

## Current Limitation

- PagedAttention 仅作为后处理（HF attention 计算 → 写入物理缓存）。AttentionBackend 未集成到 model forward
- Server 仍使用 stdlib http.server（未重构为 FastAPI）
- `runtime/model_loader.py` 和 `runtime/tokenizer.py` 保留在 runtime/ 而非移至 model_executor/
- 无 torch 环境，GPU 测试未验证
