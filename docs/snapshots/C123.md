# C123: block_pool + kv_cache_manager — extract helpers

## Goal

Tighten the hot-path methods in `BlockPool` and `KVCacheManager` by extracting small helpers. Each hot method drops to a few-line top-to-bottom pipeline that reads like nano-vllm's `BlockManager`, while preserving every C-feature (LRU eviction, ref-count cascading, CoW, prefix-cache walk).

## New Features

### `BlockHashToBlockMap` — consolidated type-dispatch

Removed the `_unexpected_type` private method. The two-branch handling (`isinstance(entry, KVCacheBlock)` vs `isinstance(entry, dict)`) is now inlined in each public method with a single `raise AssertionError(...)` at the end of each dispatch. Removed `from typing import Any` since `_unexpected_type` was the only consumer.

### `BlockPool.free_blocks` — extracted `_split_blocks_for_free`

The free-list split (with-hash vs without-hash) becomes a single helper:

```python
def free_blocks(self, blocks: list[KVCacheBlock]):
    with_hash, without_hash = self._split_blocks_for_free(blocks)
    self.free_block_queue.prepend_n(without_hash)
    for b in with_hash:
        self.free_block_queue.append(b)

def _split_blocks_for_free(
    self, blocks: list[KVCacheBlock],
) -> tuple[list[KVCacheBlock], list[KVCacheBlock]]:
    """Decrement ref_cnt; partition into (with_hash, without_hash)."""
    with_hash: list[KVCacheBlock] = []
    without_hash: list[KVCacheBlock] = []
    for b in blocks:
        if b.ref_cnt > 0:
            b.ref_cnt -= 1
        if b.ref_cnt == 0 and not b.is_null:
            b._is_free = True
            if b.block_hash is not None:
                with_hash.append(b)
            else:
                without_hash.append(b)
    return with_hash, without_hash
```

### `KVCacheManager.get_computed_blocks` — extracted `_walk_cached_prefix`

The 18-line walk loop inside `get_computed_blocks` is now a helper:

```python
def get_computed_blocks(self, request):
    if not self.block_pool.enable_caching:
        return KVCacheBlocks.empty(), 0
    block_size = self.block_pool.block_size
    max_cache_hit_length = max(0, request.num_tokens - 1)
    request.compute_block_hashes(block_size)
    cached_blocks, num_computed = self._walk_cached_prefix(
        request, max_cache_hit_length, block_size,
    )
    if cached_blocks:
        self.request_blocks[request.request_id] = cached_blocks
        return KVCacheBlocks(block_ids=[b.block_id for b in cached_blocks]), num_computed
    return KVCacheBlocks.empty(), 0

def _walk_cached_prefix(self, request, max_cache_hit_length, block_size):
    """Walk request.block_hashes, returning cached (and CoW'd) blocks."""
    cached_blocks, num_computed = [], 0
    for block_hash in request.block_hashes:
        if not block_hash: break
        if num_computed >= max_cache_hit_length: break
        cached = self.block_pool.get_cached_block(block_hash)
        if cached is None: break
        cached.ref_cnt += 1
        private = self._apply_cow(cached)
        cached_blocks.append(private)
        num_computed += min(block_size, request.num_tokens - num_computed)
    return cached_blocks, num_computed
```
