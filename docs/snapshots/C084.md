# C084: PP (Pipeline Parallel)

## Goal

按层切分模型到多个 GPU，通过 NCCL p2p send/recv 传递 activation。1F1B-lite schedule 填充 pipeline bubble。

## New Features

- `PPHandler`: is_last_stage 判断，broadcast_sampled_tokens（last rank → all stages）
- NCCL p2p `send_activation()` / `recv_activation()` between stages
- `GroupCoordinator.send()` / `recv()` — NCCL p2p primitives
- `bubble_time(pp_size, micro_batch_time)` / `efficiency(N, pp_size)` — 分析工具
