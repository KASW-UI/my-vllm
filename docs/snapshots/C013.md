# C013: Tensor Parallel

## Goal
C012 的 Executor 仅支持单 Worker，无法加载大模型。本阶段引入 Tensor Parallel 的基础设施——分布式状态管理和 Column/Row Parallel Linear 层——接口先行存在，world_size=1 时退化为普通 Linear。

## New Features
- `distributed/parallel_state.py` — 分布式状态（`init_distributed`, `all_gather`, `all_reduce`）
- `model_executor/layers/linear.py` — `ColumnParallelLinear` + `RowParallelLinear`
- Worker 新增 `rank` / `world_size` 参数
- `init_device()` 调用 `init_distributed(rank, world_size)`
- world_size=1: TP 层退化为 `nn.Linear`，collective ops 退化为 identity

## Architecture
```
world_size=1 (C013 default):
  ColumnParallelLinear.forward()
    → F.linear(x, weight, bias)    ← degraded to nn.Linear
  RowParallelLinear.forward()
    → F.linear(x, weight) + bias   ← degraded to nn.Linear
  all_gather / all_reduce
    → identity (no-op)

world_size>1 (future):
  ColumnParallelLinear.forward()
    → each rank: local linear
    → all_gather outputs           ← combine partial results
  RowParallelLinear.forward()
    → each rank: local linear
    → all_reduce                   ← sum partial results
```
