# C080: MultiprocExecutor

## Goal

C032 只有 `UniProcExecutor`（单进程）。多 GPU 需要多进程执行器管理 Worker 生命周期。

## New Features

- `MultiprocExecutor(Executor)`: 为每个 GPU rank 启动 Worker 子进程
- `_worker_main()`: 子进程入口 — CUDA device 初始化 → Worker.init_device() → 循环执行
- 通信: 简化的 `mp.Queue` 收发 SchedulerOutput / ModelRunnerOutput
- `shutdown()`: sentinel 信号 + join/terminate
