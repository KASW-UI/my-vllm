# C083: TP=2 Industrial NCCL

## Goal

C050 已在 layer 中内联 `torch.distributed` 调用，但缺少进程组初始化和抽象层。C083 补齐 `initialize_model_parallel` + `GroupCoordinator`。

## New Features

- `GroupCoordinator` — 封装 NCCL process group: all_reduce / all_gather / broadcast / send / recv
- `initialize_model_parallel(tp_size, backend)`: init_process_group + TP GroupCoordinator 创建
- `get_tp_world_size()` / `get_tp_rank()` 在未初始化时 gracefully fallback 到 1/0
- `init_model_parallel_group()` 工厂函数
