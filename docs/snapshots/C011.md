# C011: Worker

## Goal
C010 的 ModelRunner 直接暴露给 StateManager，model 和 device 初始化分散在 main.py 中。本阶段引入 Worker 抽象层，将 model 生命周期、设备初始化和 ModelRunner 封装在 Worker 内部。

## New Features
- `worker/worker_base.py` — `WorkerBase` 抽象接口
- `worker/gpu_worker.py` — `Worker` GPU 实现
- StateManager 通过 Worker 访问 ModelRunner（不再直接持有 model）
- main.py 创建 Worker 后传入 StateManager

## Architecture
```
Before (C010):
  main.py → model → StateManager → ModelRunner → model.forward()

After (C011):
  main.py → model → Worker ──► StateManager ──► Worker.get_model_runner()
                            │
                            ├─ init_device()  — model.eval(), create ModelRunner
                            └─ get_model_runner() → ModelRunner

Worker role:
  ┌──────────────────────┐
  │ Worker               │
  │  model: nn.Module    │← model lifecycle ownership
  │  device: torch.device│← device management
  │  ModelRunner         │← created on init_device()
  └──────────────────────┘
```

## Current Capability
- ✅ Worker 隔离 model 生命周期
- ✅ WorkerBase 抽象接口（可扩展多 Worker 类型）
- ✅ StateManager 通过 Worker 获取 ModelRunner
- ✅ model 和 device 封装在 Worker 内部

## Current Limitation
- ❌ 无 Executor 统一管理多个 Worker
- ❌ 无多 GPU / Tensor Parallel 支持
- ❌ WorkerBase 接口仅 `init_device()` + `get_model_runner()`

## Next Stage
多个 Worker 需要统一管理。Commit 012 引入 Executor，封装 Worker 调度和通信。
