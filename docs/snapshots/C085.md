# C085: CP (Context Parallel) / Ring Attention

## Goal

长序列沿 seqlen 维度切分到多 GPU，通过 ring send/recv KV tiles 完成分布式 attention。

## New Features

- `CPGroup(cp_size, cp_rank)`: ring 通信 topology (next_rank, prev_rank)
- `ring_attention_forward()`: cp_size 步迭代 — 本地 attention → online softmax LSE merge → 下一步
- 兼容 vLLM `scaled_dot_product_attention` fallback（单 GPU 时）
