# C069: Config 体系 — VllmConfig, ModelConfig, CacheConfig, SchedulerConfig

## Goal

C032 只有 42 行 `EngineConfig`。C069 拆出 ModelConfig / CacheConfig / SchedulerConfig，由 VllmConfig 聚合。为 Phase 2 分布式配置提供基础。

## New Features

- `ModelConfig`: model_name, dtype, max_model_len, seed
- `CacheConfig`: block_size, num_kv_blocks, enable_prefix_caching
- `SchedulerConfig`: max_num_batched_tokens, max_num_seqs, policy
- `VllmConfig`: 聚合上述三种 config + tensor_parallel_size
- `EngineConfig` 保留为 backward-compat alias
