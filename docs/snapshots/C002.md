# C002: Generation Loop

## Goal
C001 只能得到一次 logits，无法生成文本。本阶段引入 autoregressive generation loop，实现 token-by-token 文本生成。

## New Features
- `generation/sampler.py` — greedy sampling（argmax）
- `LLM.generate()` — 自回归生成循环
- 每步取最后 logits → sample → append token → 再次 forward
- 支持 max_new_tokens 和 EOS 停止

## Runtime Flow
```
input_ids
  ↓
while not EOS and < max_new_tokens:
    forward(current_ids)       ← 全序列重复计算
      ↓
    logits[:, -1, :]
      ↓
    greedy_sample()
      ↓
    next_token
      ↓
    append to current_ids
      ↓
    check EOS
```

## Current Capability
- ✅ 单请求 token-by-token 文本生成
- ✅ Greedy 采样（argmax）
- ✅ EOS 停止 / max_new_tokens 截断

## Current Limitation
- ❌ 每步重新计算全部历史 token（无 KV Cache，decode 复杂度 O(n²)）
- ❌ 无 Batch 支持
- ❌ 无 Request 对象
- ❌ 无显存管理
- ❌ 仅支持 greedy 采样

## Next Stage
Decode 阶段每步都要重新计算整个序列的 attention，计算量随序列长度平方增长。Commit 003 引入 KV Cache，将 decode 复杂度从 O(n²) 降到 O(n)。
