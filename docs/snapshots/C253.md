(EXTENDED, ~115 lines, was 52):

### 2. `NixlBaseConnector.request_finished` chains to base

`my_vllm/distributed/kv_transfer/kv_connector/v1/nixl/connector.py` —
the C250-era `NixlBaseConnector.request_finished` overrides the
C251 default.  C253 chains them so the KV index + failure tracker
cleanup runs:

```python
def request_finished(self, request, block_ids):
    rid = (
        request.request_id
        if hasattr(request, "request_id")
        else str(request)
    )
    self._kv_loaded_flags.pop(rid, None)
    self._acks.pop(rid, None)
    self._transfer_start.pop(rid, None)
    # C251 hook: also clean up the KV index + failure tracker.
    super().request_finished(request, block_ids)
```

### 3. Multi-PD-instance test (`tests/test_C253_pd_disagg_full.py`, 13 tests)

The C253 plan calls for "mock 2 producer + 4 consumer, bit-exact
K/V verify".  The new test file covers:

* **TestSingleProducerSingleConsumer** — minimal bit-exact sanity
  check (1 producer + 1 consumer).
* **TestMultiPD** — canonical 2-producer + 4-consumer scenario:
  - Each producer has its own `ExampleConnector`.
  - Each producer saves a distinct random K/V via
    `connector.save_kv_layer`.
  - Each of 4 consumers reads from the producers' SHM buffers
    and verifies bit-exact equality.
  - Every consumer subscribes to the C252 coordinator and
    receives every `BlockStored` event (no block filter).
* **TestMultiPD::test_block_stored_with_filter_triggers_only_matching**
  — consumer with a block filter (e.g. `{999}`) receives zero
  events when producers emit different block hashes.
* **TestC251SurfaceIntegration** — verifies the C251
  `KVIndex` + `KVFailureTracker` surface is inherited + the
  `update_state_after_alloc` / `request_finished` default
  lifecycle works.
* **TestMultiPDWithPagedWrite** — multi-PD scenario through
  `triton_reshape_and_cache_flash` into each consumer's paged
  cache.  Bit-exact verification at the paged-cache level.
* **TestCpGatherCacheDirect** — direct smoke test of the
  `cp_gather_cache` kernel with the documented flattened layout
  (`[num_blocks, block_size, entry_size]`).
* **TestBackwardCompat** — C212 + C250 + C251 + C252 still importable.

## Runtime Flow

```
PD disaggregation (2 producers + 4 consumers, in-process mock):

  Producer-0 (Prefill Engine Core)
    │
    ├── compute K/V for prompt
    ├── connector.save_kv_layer("layer0", k)        ← C253 override
    │     └── super().save_kv_layer(...)              ← NixlBaseConnector
    │           └── copy to SHM buffer (CPU)
    │     └── coord.publish_event(BlockStored(...))   ← C252 publish
    │           └── coordinator routes to 4 consumers
    │                 each consumer.callback(event)
    │                   └── consumer logic:
    │                         ├── record event log
    │                         ├── maybe trigger KV transfer
    │                         └── update kv_index if matching
    │
    └── connector.wait_for_save()                    ← C250 NIXL wait

  Consumer-0..3 (Decode Engine Core, parallel)
    │
    ├── connector.start_load_kv()                    ← C250 NIXL load
    │     └── pull KV from producer's SHM buffer
    │
    ├── For each block:
    │     flat_k = producer._kv_buffers["producer-0-k"][:N]
    │     flat_k = flat_k.reshape(...).cuda()
    │     triton_reshape_and_cache_flash(
    │         key=flat_k,
    │         key_cache=consumer_k_cache[0],
    │         slot_mapping=arange(N),
    │     )
    │
    ├── assert consumer_k_cache[0, 0, :N] == producer's K
    │
    └── unified_attention(q, consumer_k_cache, consumer_v_cache)  ← bit-exact
```

## Current Capability

* **Multi-PD-instance coordination** — 2 producers + 4 consumers
  in-process mock with bit-exact K/V verification.
* **C253 EventBus integration** — `ExampleConnector.save_kv_layer`
  publishes `BlockStored` events to the C252 coordinator; consumers
  subscribe and receive events.
* **C251 surface** — `kv_index`, `failure_tracker`, metadata
  lifecycle, partial transfer all inherited automatically.
* **`get_num_new_matched_tokens`** — returns the largest pending
  bundle's token count.
* **`build_connector_worker_meta`** — per-step stats.
* **Bit-exact paged-cache write** — `triton_reshape_and_cache_flash`
  + the producer's saved buffer produces a paged cache identical to
  the producer's original K/V.
* **`request_finished` chains** — NIXL connector cleanup +
  C251 base cleanup both run.

## Current Limitation

1. **Single-process only** — the C242 SHM broadcast primitive is
   the cross-process substitute (not vendored here).  Production
   multi-host PD would need the C242 wire-up.
2. **No NIXL runtime** — the actual RDMA backend is still skeleton
   (C250 protocol-only layer).
3. **No cross-engine handshake** — the C250 `compute_handshake`
   uses a JSON placeholder for the NIXL agent descriptor.
4. **No real producer_engine_id** — `ExampleConnector.save_kv_layer`
   uses `"example"` as the producer_engine_id (no formal producer
   registration for this debug connector).
5. **No real `cp_gather_cache` integration** — the test uses
   `triton_reshape_and_cache_flash` for the paged-cache write
   (the canonical path).  `cp_gather_cache` works with a different
   layout (flattened `[num_blocks, block_size, entry_size]`).
6. **No actual KV transfer trigger** — the coordinator records
   triggers but does not issue NIXL READ transfers.  The
   integration point is `get_num_new_matched_tokens` on the consumer.
