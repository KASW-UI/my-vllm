# C020: GPU Request State

## Goal

Replace Python-dict per-request state (_steps, _next_token, _req_index)
with GPU tensor-backed RequestState, enabling CUDA Graph compatibility
and consistent tensor shapes.

## New Features

- `v1/worker/gpu/states.py` — RequestState class:
  - `all_token_ids`: [max_reqs, max_model_len] int32 GPU tensor
  - `num_computed_tokens_cpu`: np.ndarray [max_reqs] int32 (CPU mirror)
  - `last_sampled_tokens`: [max_reqs, 1] int64 GPU tensor
  - `add_request(req_id, prompt_token_ids)` → assigns slot index
  - `append_output_token(req_id, token)` → auto-increment writes
  - `remove_request(req_id)` → frees slot
  - `req_id_to_index` / `index_to_req_id` / `free_indices`
- GPUModelRunner: _steps → RequestState.get_step(), _next_token →
  RequestState.last_sampled_tokens, _req_index → RequestState.req_id_to_index
- Mirrors vLLM V1 `v1/worker/gpu/states.py:9` (simplified:
  regular torch.Tensor instead of StagedWrite/UVA)

## Current Limitation

- No StagedWrite/UVA buffers (not needed without CUDA Graph)
- all_token_ids stored as regular GPU tensor (not UVA)
- No speculative decoding support (draft_tokens omitted)
