# C113: forward_context.py + attention_layer_base.py — metadata channel

## Goal

Align `my_vllm/forward_context.py` and `my_vllm/model_executor/layers/attention_layer_base.py` with the real vLLM source. These two files form the **metadata channel** through which the runner tells attention layers how to execute the current forward pass (attn_metadata, slot_mapping, cudagraph mode). C114+ (Attention layer / QKVParallelLinear / custom OPT) and C119 (CUDA graph) depend on this channel having the right shape.

## New Features

### `forward_context.py`

Mirrors `vllm/vllm/forward_context.py` (subset):

- **`CUDAGraphMode` enum** (NONE / PIECEWISE / FULL) — runtime subset of vLLM's tuple-mode enum.
- **`BatchDescriptor`** dataclass (frozen) — `(num_tokens, num_reqs, uniform)` batch fingerprint for CUDA-graph dispatch.
- **`ForwardContext`** extended with:
  - `attn_metadata: dict[str, Any]` — per-layer attention metadata (existing).
  - `slot_mapping: dict[str, torch.Tensor]` — per-layer slot_mapping (separated from `attn_metadata`, mirroring vLLM).
  - `cudagraph_runtime_mode: CUDAGraphMode` — defaults to NONE.
  - `batch_descriptor: BatchDescriptor | None` — defaults to None.
  - `additional_kwargs: dict[str, Any]` — existing, reserved for platform extras.
- **`get_forward_context()`** — unchanged API, returns global ctx.
- **`is_forward_context_available()`** — new; mirrors vLLM.
- **`override_forward_context(ctx)`** — new; mirrors vLLM, used for nested context swaps.
- **`set_forward_context(...)`** — extended signature with `cudagraph_runtime_mode`, `batch_descriptor`, `slot_mapping`. Auto-extracts `slot_mapping` from `attn_metadata[0].slot_mapping` when not explicitly provided (back-compat with the current runner that packs slot_mapping inside `CommonAttentionMetadata`).
- `set_forward_context` now `yield`s the active `ForwardContext` to its caller (mirrors vLLM).

### `attention_layer_base.py`

Mirrors `vllm/vllm/model_executor/layers/attention_layer_base.py`:

- **`AttentionLayerBase` ABC** with proper type annotations:
  - `impl: "object"]` (forward reference to `AttentionImpl`).
  - `supports_dcp: bool = True` (default, forward-compat).
  - `bind_kv_cache(kv_cache: torch.Tensor | tuple[torch.Tensor, ...])` — type widened to accept separate K/V tuple (matches real vLLM and the current runner's `bind_kv_cache((k, v))` call).
  - `@abstractmethod get_attn_backend()` — typed return as `type[object]`.
  - `@abstractmethod get_kv_cache_spec(vllm_config)` — preserved.
- Imports updated; no behavior change at the base class level.

## Runtime Flow

```
GPUModelRunner.execute_model()
   │
   ├─ _update_states()        # build block_table + slot_mapping
   ├─ _execute_prefill()      # build CommonAttentionMetadata (has slot_mapping)
   │     └─ set_forward_context(attn_metadata_dict,
   │                            slot_mapping=per_layer_slot_dict)
   │           └─ with ctx active:
   │                model(input_ids, positions)  # OPTForCausalLM
   │                   └─ for each layer: Attention.forward(q, k, v)
   │                        └─ get_forward_context().attn_metadata[layer_name]
   └─ _execute_decode()       # same shape, single-token queries
```

## Current Capability

- `python run.py` runs end-to-end and produces the same output as before (`Hello, my name is ropesission`).
- All imports resolve; no test regressions vs. pre-C113 baseline (191 passed / 55 failed — same as baseline; failures are pre-existing and unrelated).
- ForwardContext now exposes the fields CUDA-graph dispatch (C119) and Triton paged-attention metadata plumbing (C117) need.

## Current Limitation

- `cudagraph_runtime_mode` and `batch_descriptor` are wired into ForwardContext but not yet **read** anywhere. C119 will consume them.
- `slot_mapping` separation is symbolic: the current runner still packs slot_mapping inside `CommonAttentionMetadata`; `set_forward_context` auto-extracts it. C117 will split it cleanly into a top-level dict.
- `DPMetadata` / `UBatchSlices` are intentionally absent (no DP / no Microbatching in my-vllm basic runtime).
