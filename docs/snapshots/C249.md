## Current Capability (Phase 4)

* **All-to-All (EP/DP)**: `AgRsAll2AllManager` real impl; DeepEP /
  NIXL / FlashInfer / Mori backends as class shells.
* **Symmetric Memory (NVLS)**: NVLS fast-path with graceful
  disable on non-NVLS hardware.
* **SHM Broadcast + Object Storage**: lock-free ring buffer +
  same-host MessageQueue.
* **Weight Transfer**: NCCL / sparse NCCL / IPC backends; packed
  tensor mechanics; factory + lazy registry.
* **Async Scheduler**: SPSC lock-free + MPMC cross-thread queues.
* **KV-aware scheduling**: opt-in budget estimation + occupancy
  ceiling.
* **EP elastic rebalance**: state machine + threshold policy +
  callback shells for production wire-up.
* **Distributed comm benchmark**: 5 collectives × 5 backends,
  single CSV harness.
* **16 engineering notes**: 5,698 lines.

## Current Limitation (Phase 4)

1. **Naive all_to_all is O(P²)** — production EP needs DeepEP /
   FlashInfer NVLink / NIXL EP kernels (50K+ LOC not vendored).
2. **SymmMem requires NVLS hardware** (Hopper+) — disabled on
   RTX 4060 (sm_89).
3. **Custom AR is single-node only** (CUDA IPC; world_size 2..8).
4. **Weight transfer requires manual PG setup** — no
   `StatelessProcessGroup` vendor, no Ray actor / HTTP RLHF
   routes.
5. **EP elastic rebalance has callback shells** — production
   wire-up to TCPStore + NCCL + EPLB is deferred.
6. **Single-rank benchmark measures Python overhead, not real BW**.
7. **2 pre-existing C212 test pollution failures** (isolated 5/5).
